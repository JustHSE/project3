# 🌡️ Анализ многодневных данных сенсора (LB4)

Консольное приложение для анализа температурных данных с датчиков на C++.

## 📋 Описание

Программа обрабатывает двумерный массив данных с измерениями температуры за несколько дней: вычисляет среднюю температуру и выявляет дни с повышенной температурой.

## 🎯 Основные функции

- **Ввод данных** - чтение количества дней и измерений в день, ввод значений температуры
- **Вычисление средних** - расчёт средней температуры за день и общей средней
- **Анализ теплых дней** - выявление дней с температурой выше среднего
- **Вывод результатов** - отображение общей статистики и списка теплых дней

## 💾 Технические особенности

- Максимум дней: 30
- Максимум измерений в день: 24
- Использование двумерных динамических массивов
- Работа с указателями на указатели (float**)
- Арифметика указателей без использования [i][j]
- Поддержка UTF-8 кодировки на Windows
- Только разрешённые библиотеки: `iostream`, `iomanip`
- Без использования классов и STL

## 📝 Пример использования

```
=== Анализ многодневных данных сенсора ===
Введите количество дней: 3
Введите количество измерений в дне: 4
День 1: 10 12 14 11
День 2: 5 4 7 8
День 3: 20 22 25 21

Общая средняя температура: 12.6

Теплые дни:
День 3 (среднее = 22.0)
```
